# Architecture Decision Records

Use this folder for bounded, traceable architecture and workflow decisions that should live with the repository.

## Naming

- Copy `0000-template.md` to the next available ADR number.
- Prefer short kebab-case titles, for example `0001-adopt-uv.md`.
- Keep ADRs scoped to one decision each.

## Expectations

- State the context, decision, consequences, and scope boundaries clearly.
- Prefer minimal diffs and evidence-first reasoning.
- Do not use ADRs to widen deferred runtime or authority surfaces without a separately validated slice.
